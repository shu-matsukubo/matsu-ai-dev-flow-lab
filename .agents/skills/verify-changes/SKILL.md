# 提供能力

成果物に必要な静的確認、テスト、build、再現操作を実行し、項目ごとの結果と保証範囲を返す。

## 適用条件

- 検証対象のrevisionまたは固定された成果物を取得できる。
- 要求、設計、検証基準、利用可能な環境を確認できる。
- 実行が承認範囲と安全境界に含まれる。

## 入力

- 対象成果物とrevision
- 要求、受入条件、現在の設計
- 検証基準と期待結果
- 利用可能な実行環境、権限、依存関係
- 既知の変更リスク

## 出力

各確認について次を返す。

- 対象と確認方法
- 期待結果
- `Passed`、`Failed`、`Not Executed`の結果
- 終了値と主要な証拠
- 失敗または未実施の理由
- 受入条件への対応
- `Remaining Risk`
- 検証中に観測したフロー上の問題

## 責務外

- 検証結果を受けた成果物の修正
- 検証項目のscope外への拡張
- 記録または工程状態の更新
- branch、commit、Pull Request、Issueの操作
- 別能力の呼び出し、再実行または提出の決定

## 能力固有の処理

検証基準から共通品質ゲートとリスク固有の追加確認を特定する。revisionを固定して実行し、コマンドまたは再現手順、終了結果、主要出力を保存する。文書や構造変更ではリンク、契約、禁止依存、fixtureなど、変更の失敗モードを直接検出する確認を含める。

実行できなかった確認を成功へ読み替えない。一部だけ実行できた場合は項目ごとに分ける。テストの成功と、そのテストが覆わない保証範囲を区別する。

## 失敗・未実施・残るリスク

環境、権限、依存関係、時間制約で実行できない場合はNot Executedとして理由、代替確認、影響を返す。Failedは再現可能な証拠とともに返す。すべてPassedでも未網羅の経路や外部条件をRemaining Riskとして明示する。
