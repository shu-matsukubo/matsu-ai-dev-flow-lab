# workspace runnerの起動失敗がローカル検証とブラウザ操作を同時に妨げる

- 発生元Issue: #35
- 発生元Task: 35-01
- 発生元PR: なし（Task PR作成前）
- category: tool-runtime
- symptom: workspace commandとBrowser操作の実行環境が起動時に終了し、ローカルcommandおよび署名済みGitHub画面の操作を開始できない
- impact: `sh scripts/verify.sh`、local git状態確認、repository既定branch変更、ラベル一覧の機械確認を実行できず、GitHub連携によるremote-only作業と人間操作への引き渡しが必要になった
- evidence: `exec_command`は複数回 `windows sandbox failed: helper_unknown_error: setup refresh had errors` で起動失敗し、Browser接続も複数回 `trusted Node process exited unexpectedly` で終了した
- suggestion: workspace runnerの起動前health checkで失敗箇所と復旧操作を返し、再起動後も同じ失敗が続く場合にローカル検証とBrowser操作を個別に復旧できる経路を用意する
